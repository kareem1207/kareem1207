## 🚀 Featured Projects

### Aura — AI-Powered Agentic Web Browser & Productivity Suite

A desktop browser that can be told what to do instead of clicked through. Multi-tab navigation, isolated profile partitions (Spaces), collapsible tab groups, split-view layouts and stateful session recovery — plus an autonomous automation pipeline built on a unified `ModelRouter` for local/remote LLMs and a `TaskExecutionEngine` (Planner → ActionResolver → Verifier). Ships with an in-app office suite for documents, spreadsheets and PDFs, accelerated by a custom Rust-to-WebAssembly file engine and Tesseract.js OCR.

Stack: Electron · React · Node.js · Go · Rust · WebAssembly · Gemini · Claude · OpenAI · Ollama

🔒 Closed source — Aura is my own browser and stays confidential. Happy to walk through the architecture.

### GridSense AI — Predictive Grid Fault Intelligence

Power infrastructure fails loudly and late. GridSense ingests thousands of live meter feeds over MQTT, predicts transformer failures 48–72 hours ahead, and hands field engineers a plain-language work order instead of a dashboard to decode. Fault-tolerant telemetry pipeline in Java/Spring Boot + Kafka across 5,000+ smart meters and 100 transformer units; dual-model analytics using TensorFlow LSTM autoencoders and scikit-learn Isolation Forest; LangChain diagnostic agent doing RAG over a vector database.

Stack: Java · Spring Boot · Apache Kafka · MQTT · TimescaleDB · TensorFlow · LangChain · FastAPI · Python • [Repository →](https://github.com/kareem1207/GridSense-AI)

### Aizy — Full-Stack Platform with AI Analytics

[![Aizy](./images/Projects/aizy-logo.jpg)](https://github.com/kareem1207/Aizy)

AI-driven e-commerce platform with three separate domains for customers, sellers and admins. Next.js front end, Express.js + FastAPI services, hybrid MongoDB/MySQL architecture via Prisma ORM and Mongoose, with Random Forest and ARIMA models for recommendation and trend forecasting.

Stack: Next.js · Express · FastAPI · MongoDB · MySQL · Prisma · Tailwind · JWT • [Repository →](https://github.com/kareem1207/Aizy)
